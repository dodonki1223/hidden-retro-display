# Hidden Retro Display

## プロジェクト概要

仕事環境を維持したまま、机の下に収納された大型ディスプレイを展開し、
床に座って快適にレトロゲームを楽しめるシステムを構築する。

---

## プロジェクトの目的

- 仕事中はゲーム環境を見せない
- 数秒でゲーム環境へ切り替えられる
- 昇降デスクの機能を維持する
- 安全で長期間使用できる構造にする
- 将来的な拡張にも対応する
