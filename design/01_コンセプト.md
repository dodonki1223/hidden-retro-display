# コンセプト設計

## コンセプト

机の下にゲーム用ディスプレイを収納し、ゲーム時だけ机の正面側へ展開する。

## 収納時

```text
仕事用24インチディスプレイ    仕事用24インチディスプレイ

==================== 天板 ====================

[ ゲーム用ディスプレイは天板下に収納 ]
```

## 使用時

```text
仕事用24インチディスプレイ    仕事用24インチディスプレイ

==================== 天板 ====================
                      \
                       \
                    [ ゲーム用ディスプレイ ]

                 ユーザーは床に座ってプレイ
```

## 想定サイズ

第一候補は32インチ級。

理由:

- 24インチより大きい体験が得られる
- 40インチ以上より軽く、安全設計しやすい
- 1400mm幅の机下に収まりやすい

## 重要な設計ポイント

- 天板裏フレームを避ける
- 補強板で荷重を分散する
- 落下防止ワイヤーを追加する
- 昇降時にケーブルが引っ張られないようにする
- ケーブルトレーとの干渉を確認する
