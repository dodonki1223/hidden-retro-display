# ビジョン

Hidden Retro Display は、仕事環境を崩さずに、床座りでレトロゲームを快適に遊ぶための机下収納型ディスプレイシステムである。

## 理想の体験

### 仕事中

- ゲーム用ディスプレイが視界や作業スペースの邪魔にならない
- 既存の24インチディスプレイ2枚とEDIFIER M60をそのまま使える
- 昇降デスクとして通常どおり使える

### ゲーム開始時

- 椅子をどけて床に座る
- 机下のディスプレイを展開する
- PS2を起動してすぐ遊べる

### ゲーム中

- 24インチより大きい画面で遊べる
- スピーカーは既存のEDIFIER M60を流用する
- 配線が足元で邪魔にならない

### メンテナンス

- 昇降デスクのモーターやフレームの点検を妨げない
- ディスプレイ交換や配線変更ができる
- 必要に応じて分解できる

## 設計思想

- DIYではなく、製品開発に近い品質を目指す
- 机本体の加工は最小限にする
- 安全率を重視する
- 市販部品を優先して使う
- 試作してから本番組立に進む
