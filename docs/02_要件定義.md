# 要件定義

## 前提

- 机は昇降式デスクを使用する
- 机の正面に床座りしてゲームをする
- 机上には仕事用の24インチディスプレイが2枚ある
- ゲーム用ディスプレイは24インチより大きい画面を想定する
- 主なゲーム機はPS2
- PS2は机横の棚に置く想定
- スピーカーは既存のEDIFIER M60を流用する

## Must（必須）

- 仕事中はゲーム用ディスプレイが邪魔にならないこと
- 床に座って快適にゲームができること
- 昇降デスクの昇降機能を維持すること
- ディスプレイが落下しないこと
- 配線が足元や昇降機構に干渉しないこと
- EDIFIER M60を流用できること
- PS2で利用できること
- 昇降デスクのモーター・フレーム・シャフトのメンテナンスを妨げないこと

## Should（できれば）

- 32インチ程度のディスプレイを使うこと
- ディスプレイはVESA対応であること
- ディスプレイ重量はできれば6kg以下にすること
- 机本体への加工を最小限にすること
- ケーブルトレーと干渉しないこと
- 将来的に他ゲーム機へ拡張できること
- 部品交換・分解がしやすいこと

## Could（将来的）

- HDMI切替器を追加する
- Switchや他ゲーム機にも対応する
- ワンタッチ展開にする
- LED照明を追加する
- 電動展開機構を追加する

## 対象外

- ゲーム機を机下へ完全収納すること
- 新規スピーカーを購入すること
- 仕事用24インチディスプレイの配置変更
- 机そのものの大規模改造
