# リスク管理

## 機械的リスク

| リスク | 内容 | 対策 |
|---|---|---|
| ディスプレイ落下 | 取り付け部が外れて落下する | 補強板、落下防止ワイヤー、安全率の確保 |
| 天板変形 | 重量やモーメントで天板がたわむ | 荷重分散、軽量ディスプレイ採用 |
| 昇降機構干渉 | フレーム・モーター・シャフトに当たる | 天板裏寸法測定、試作確認 |
| ケーブルトレー干渉 | 収納時にトレーとぶつかる | トレー位置変更または薄型化 |
| 指挟み | 開閉時にヒンジ周辺で指を挟む | 可動部カバー、操作手順の明確化 |

## 電気的リスク

| リスク | 内容 | 対策 |
|---|---|---|
| ケーブル引っ張り | 昇降時や展開時にケーブルが張る | 余長確保、ケーブルガイド設置 |
| HDMI断線 | 可動部で繰り返し曲げられる | 柔らかいケーブル、固定点の設計 |
| 電源ケーブル干渉 | 足元や可動部に絡む | 配線ルート固定 |

## 使用時リスク

| リスク | 内容 | 対策 |
|---|---|---|
| 膝・足の衝突 | 床座り時にディスプレイや金具へ当たる | 使用時レイアウト確認 |
| 首が疲れる | 画面位置や角度が合わない | 目線高さと距離を測定して設計 |
| 収納忘れ | 収納せずに仕事を始める | 収納状態チェックを運用に入れる |

## 現時点で最重要の確認事項

1. 天板厚み
2. 天板裏フレーム位置
3. 取り付け可能スペース
4. ディスプレイ重量
5. VESA規格
