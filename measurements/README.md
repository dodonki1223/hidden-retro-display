# 測定記録

このディレクトリでは、設計に必要な寸法を管理する。

## 測定が必要な項目

### デスク

| 項目 | 値 | メモ |
|---|---:|---|
| 天板幅 | 1400mm | 既知 |
| 天板奥行 | 700mm | 既知 |
| 天板厚み | 未測定 | 最重要 |
| 最低時の床〜天板裏 | 未測定 | 床座り設計に必要 |
| 最高時の床〜天板裏 | 未測定 | ケーブル余長設計に必要 |

### 天板裏

| 項目 | 値 | メモ |
|---|---:|---|
| 奥端から白いフレームまで | 未測定 | 干渉確認 |
| フレーム幅 | 未測定 | 補強板設計 |
| モーター位置 | 未測定 | 干渉確認 |
| シャフト位置 | 未測定 | 干渉確認 |
| ケーブルトレー寸法 | 未測定 | 収納干渉確認 |

### 床座り

| 項目 | 値 | メモ |
|---|---:|---|
| 床から目線まで | 未測定 | 画面高さ設計 |
| 顔から机前端まで | 未測定 | 視聴距離設計 |
| 床座り時の足の位置 | 未確認 | 干渉確認 |
