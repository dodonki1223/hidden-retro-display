# 写真管理

このディレクトリでは、設計・試作・組立に使う写真を管理する。

## 推奨ディレクトリ

```text
photos/
├── desk/       # 現在の机・天板裏・配線状態
├── concept/    # コンセプト画像・イメージ図
├── prototype/  # 試作写真
├── assembly/   # 組立中の写真
└── final/      # 完成写真
```

## 現時点で欲しい写真

- 真下から見た机全体
- 正面から見た机全体
- 左側から見た机下
- 右側から見た机下
- 横から見た机と床座り位置
- ケーブルトレー周辺
- モーター・シャフト周辺

## コンセプト画像について

現時点のコンセプト画像は会話内で作成済み。
リポジトリへ保存する場合は `photos/concept/` に追加する。
